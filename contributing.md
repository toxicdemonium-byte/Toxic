Adding something to an awesome list
If you have something awesome to contribute to an awesome list, this is how you do it.

You will need a GitHub account! If you are new to GitHub, get started here.

Access the awesome list's GitHub page. For example: https://github.com/sindresorhus/awesome
Click on the readme.md file: Step 2 Click on Readme.md
Now click on the edit icon. Step 3 - Click on Edit
You can start editing the text of the file in the in-browser editor. Make sure you follow the guidelines above. You can use GitHub Flavored Markdown. Step 4 - Edit the file
Say why you're proposing the changes, and then click on "Propose file change". Step 5 - Propose Changes
Submit the pull request!
